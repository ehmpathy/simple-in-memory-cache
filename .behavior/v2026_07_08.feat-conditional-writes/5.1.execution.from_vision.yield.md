## findings during execution

1. **version()/condition impedance** — `version()` returns `string | undefined` (undefined = absent) but
   `condition.version` wants `string | null`. this is inherent to the shipped contract (reader uses
   undefined, condition uses null). consumers must narrow; tests use a `tokenOf()` guard. not a defect —
   the two sentinels mean different things (undefined = "no token"; null = "must be absent").
2. **default-expiration test trap** — a cache created with `{ expiration: { seconds: 0 } }` expires *every*
   write instantly, including the put-if-absent write under test. fixed by giving the observed write an
   explicit ttl. the impl was correct; the test setup was the bug.
3. **dev-only beats peer** — refined the vision's peer+dev to dev-only (see todo 1). confirmed by wisher.

## follow-up (out of scope for #19)

- **wrapper converge** — `with-simple-cache`'s `exception: 'ignore'` converge does `instanceof` its own

  `with-simple-cache` to make that guard **structural on the class name** (both classes extend
