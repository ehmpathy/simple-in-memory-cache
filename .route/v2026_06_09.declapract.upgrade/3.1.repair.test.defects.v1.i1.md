## defects

### defect 1: dpdm cycle in transitive dependency

**what**: lint:cycles failed with circular dependency in `helpful-errors@1.5.3`

```
• Circular Dependencies
  1) node_modules/.pnpm/helpful-errors@1.5.3/node_modules/helpful-errors/dist/HelpfulError.js
     -> node_modules/.pnpm/helpful-errors@1.5.3/node_modules/helpful-errors/dist/withHelpfulError.js
```

**how** (what changed?):

```sh
git diff origin/main -- package.json
```

```diff
-    "test:lint": "npm run test:lint:biome && npm run test:lint:deps",
+    "test:lint": "npm run test:lint:biome && npm run test:lint:cycles && npm run test:lint:deps",
+    "test:lint:cycles": "dpdm [flags] 'src/**/*.ts'",
+    "dpdm": "4.0.1",
```

the upgrade added dpdm cycle detection. traced dependency chain via `pnpm why helpful-errors`:
- src/cache.ts imports iso-time
- iso-time@1.11.1 depends on simple-log-methods@1.2.2
- simple-log-methods@1.2.2 depends on helpful-errors@1.5.3
- helpful-errors@1.5.3 has internal cycle (fixed in 1.7.3)

**why**: the declapract upgrade did not cause this directly. the cycle exists in a transitive dependency. dpdm scans `src/**/*.ts` but resolves imports into node_modules, where the old version lives.

**fix**: upgraded iso-time from 1.11.1 to 1.11.7:
```sh
pnpm add iso-time@1.11.7
```

iso-time@1.11.7 pulls simple-log-methods@1.3.1 which uses helpful-errors@1.7.3 (no cycles).
