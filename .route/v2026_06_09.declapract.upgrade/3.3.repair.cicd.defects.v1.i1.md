## defect 1: keyrack firewall failure

### what

CI failed at "keyrack firewall" step with:

```
BadRequestError: extended keyrack not found

{
  "path": ".agent/repo=bhuild/role=dispatcher/keyrack.yml",
  ...
  "from": ".agent/keyrack.yml"
}
```

### how (diff against origin/main)

the `.agent/keyrack.yml` file was updated by the upgrade to extend three role keyrack files:

```yaml
extends:
  - .agent/repo=bhrain/role=reviewer/keyrack.yml
  - .agent/repo=bhuild/role=dispatcher/keyrack.yml  # new
  - .agent/repo=ehmpathy/role=mechanic/keyrack.yml
```

but the `prepare:rhachet` command only linked these roles:

```
mechanic behaver driver reviewer librarian ergonomist architect
```

`dispatcher` was not included, so its keyrack.yml symlink was never created.

### why (root cause)

the declapract upgrade added `bhuild/role=dispatcher/keyrack.yml` to the keyrack.yml extends list, but did not update the `prepare:rhachet` command to include the dispatcher role.

when CI runs `prepare:rhachet`, it creates symlinks only for the roles listed. since dispatcher was not listed, the symlink to `.agent/repo=bhuild/role=dispatcher/keyrack.yml` was never created. when `keyrack firewall` tried to expand the extends, it failed.

### fix

add `dispatcher` to the `prepare:rhachet` roles list in package.json:

```diff
-"prepare:rhachet": "rhachet init --keys --hooks --roles mechanic behaver driver reviewer librarian ergonomist architect"
+"prepare:rhachet": "rhachet init --keys --hooks --roles mechanic behaver driver reviewer librarian ergonomist architect dispatcher"
```
