## defect 1: dpdm cycle in helpful-errors

### classification: repo quirk

this is an ecosystem issue, not a practice defect.

### why

the cycle was extant in `helpful-errors@1.5.3`, a transitive dependency:

```
iso-time@1.11.1 → simple-log-methods@1.2.2 → helpful-errors@1.5.3
```

the upgrade added dpdm cycle detection, which revealed a pre-extant cycle in the dependency tree. this is not something declapract practices caused or should prevent.

### fix

local fix only: upgraded iso-time to 1.11.7, which pulls helpful-errors@1.7.3 (no cycles).

### action

none. no change to declapract practices needed.

## defect 2: depcheck unused dependencies

### classification: practice bug

the `.depcheckrc.yml` best-practice template is incomplete.

### evidence

packages flagged:
- `type-fns`
- `test-fns`
- `rhachet-roles-rhachet`

**declapract repo uses test-fns in its own .depcheckrc.yml:**

```sh
$ rhx git.repo.get lines --in ehmpathy/declapract-typescript-ehmpathy --paths '.depcheckrc.yml'
```

```yaml
# .depcheckrc.yml (root, line 23)
- test-fns
```

**but the best-practice template does not include it:**

```sh
$ rhx git.repo.get lines --in ehmpathy/declapract-typescript-ehmpathy --paths 'src/practices/lint/best-practice/.depcheckrc.yml'
```

```yaml
# src/practices/lint/best-practice/.depcheckrc.yml
ignores:
  - "@src/*"
  - "@src/.*"
  - rhachet
  - rhachet-brains-anthropic
  - rhachet-brains-xai
  - rhachet-roles-bhrain
  - rhachet-roles-bhuild
  - rhachet-roles-ehmpathy
  # ... (no test-fns, type-fns, or rhachet-roles-rhachet)
```

### gap analysis

| package | in declapract root | in best-practice template |
|---------|-------------------|---------------------------|
| test-fns | yes (line 23) | no |
| type-fns | no | no |
| rhachet-roles-rhachet | no | no |

the upgrade added these packages but the practice template lacked the corresponding ignores.

### action

file issue or pr to add to `src/practices/lint/best-practice/.depcheckrc.yml`:

```yaml
- test-fns
- type-fns
- rhachet-roles-rhachet
```

